# 📲 WhatsApp Bulk Sender

> تطبيق احترافي لإرسال رسائل واتساب جماعية بشكل آمن ومنظم عبر 360dialog API

---

## ✨ المميزات

- ✅ إرسال رسائل نصية + صور + روابط
- ✅ رفع قائمة الأرقام من ملف CSV أو Excel
- ✅ شريط تقدم مباشر لمتابعة الإرسال
- ✅ سجل تفصيلي بكل رسالة نجحت أو فشلت
- ✅ تأخير تلقائي بين الرسائل لحماية الرقم من الحظر
- ✅ يعمل من أي جهاز أو موبايل بدون تنزيل أي برنامج

---

## 🚀 طريقة الاستخدام

1. افتح الرابط من أي جهاز أو متصفح
2. أدخل **API Key** و **Phone Number ID** من 360dialog (مرة واحدة فقط)
3. اكتب نص الرسالة (مع صورة أو رابط اختياري)
4. أضف الأرقام من ملف CSV أو الصقها مباشرة
5. اضغط **إرسال** وتابع التقدم مباشرة ✅

---

## 🔧 المتطلبات

- حساب **Meta Business** مفعّل
- اشتراك في **360dialog** ($49/شهر)
- **API Key** و **Phone Number ID** من لوحة 360dialog
